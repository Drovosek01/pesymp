Утилита для поиска функций/переменны/символов в PE-бинарниках на Windows и вывода их адресов.

## Предисловие

Данная утилита создана на основе идеи утилиты symp ([Antibioticss/symp](https://github.com/Antibioticss/symp) и [Drovosek01/symp](https://github.com/Drovosek01/symp)).

В основном я создавал эту утилиту для того, чтобы получать адреса функций `WinVerifyTrust` в exe, dll и других PE-файлов без ожидания пока файла проанализируется в IDA Pro (потому что это ощутимо долго).

Разумеется утилита создана руководствуясь помощью нейронных сетей.
